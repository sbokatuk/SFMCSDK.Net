## What's changed

First release of the cross-platform façade over the SFMC SDK core bindings.

- **One API on both platforms**: `SfmcSdkClient` with awaitable `InitializeAsync`, `Identity`
  (profile id / contact key, string attributes) and `TrackCustomEvent`, over
  [`SFMCSDK.Net.Android 3.1.1.1`](https://github.com/sbokatuk/SFMCSDK.Net.Android/releases/tag/v3.1.1.1)
  and [`SFMCSDK.Net.iOS 4.0.1.1`](https://github.com/sbokatuk/SFMCSDK.Net.iOS/releases/tag/v4.0.1.1),
  pinned exactly. The version names the iOS line (SFMCSDK 4.0.1); the Android side is sfmcsdk 3.1.1.
- **The platform asymmetries are absorbed, not papered over**: Android's `configure` callback
  becomes an await with an options-driven timeout linked to the caller's `CancellationToken`;
  iOS completes after the state machine settles, because with zero modules configured its
  completion block never fires - measured upstream behaviour, encoded in the binding
  repository's device tests and documented in `Platforms/Apple`.
- **Sharp edges filed off**: a custom event name the native SDK rejects throws
  `ArgumentException` on both platforms (raw Android returns null and drops the event; raw iOS
  returns nil), and a second `InitializeAsync` throws the one-shot guard instead of racing a
  native configure that upstream forbids repeating.
- **Nine target frameworks** - `net8.0`, `net9.0`, `net10.0`, each with `-android` and `-ios`
  heads. The plain assets restore anywhere and throw `PlatformNotSupportedException` naming the
  platform heads, so shared class libraries, unit tests and a MAUI app's Windows head reference
  the package with no conditionals.
- **Nothing is hidden**: the raw namespaces `Com.Salesforce.Marketingcloud.Sfmcsdk` and
  `SFMCSDK` arrive with the package on their platform - module configuration (MobilePush and
  friends), consent, the event bus and the rest stay one `using` away.
- Licence is plain `MIT`: this package ships no native binaries; Salesforce's BSD-3-Clause
  arrives with the binding packages, each of which declares and packs both texts.
